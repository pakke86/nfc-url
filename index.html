Tips för iPhone & andra webbläsare: Web NFC kräver Chrome på Android. För iPhone och PC rekommenderas gratisappen NFC Tools:

  1. Klicka "Kopiera URL" ovan
  2. Öppna appen NFC Tools (eller NXP TagWriter)
  3. Välj Write (Skriv) → Add a record (Lägg till post)
  4. Välj URL / URI och klistra in länken
  5. Klicka Write och håll taggen mot telefonen!
