Tips för iPhone & PC: Web NFC kräver Chrome på Android. För iPhone och PC rekommenderas gratisappen NFC Tools:

  1. Klicka "Kopiera" ovan
  2. Öppna appen NFC Tools
  3. Välj Write (Skriv) → Add a record (Lägg till post)
  4. Välj URL / URI och klistra in
  5. Klicka Write och håll taggen mot telefonen!
